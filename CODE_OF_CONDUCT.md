# Code of conduct

Be respectful and constructive when participating in this project.

## Expected behavior

- Discuss ideas and code on their technical merits.
- Give specific, actionable feedback.
- Assume good faith while still being clear about problems.
- Respect different backgrounds, experience levels, and communication styles.
- Keep issues and pull requests relevant to the project.

## Unacceptable behavior

Harassment, threats, discrimination, personal attacks, doxxing, sexualized conduct, and deliberate disruption are not acceptable in project spaces.

## Enforcement

Project maintainers may edit, hide, or remove comments and contributions that violate this policy, and may temporarily or permanently restrict participation when necessary.

For sensitive conduct reports, use a private contact path rather than posting personal details publicly.
